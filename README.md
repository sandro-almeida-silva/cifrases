# Cifrases

Plataforma musical para descobrir, tocar, sincronizar e apresentar músicas.

A primeira experiência nasce para apoiar músicos de uma paróquia, mas o produto é genérico: qualquer tipo de música pode ser catalogado, tocado e apresentado.

## Experiências

- Biblioteca
- Modo músico
- Editor
- Modo celebração 16:9
- Temas por comunidade ou contexto

## Desenvolvimento

```bash
pnpm install
pnpm dev
```

Antes de abrir um PR:

```bash
pnpm check
```
