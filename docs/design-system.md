# Design System

O Cifrases tem identidade própria e usa princípios de softwares musicais modernos sem copiar identidade visual de terceiros.

## Direção

- Dark-first
- Superfícies em camadas
- Tipografia forte
- Conteúdo musical como protagonista
- Roxo azulado como cor de produto
- Dourado quente como acento
- Controles confortáveis para toque
- Movimento funcional

A identidade visual da paróquia é um tema de comunidade, não uma dependência do núcleo.
